# Project Title "Rock, Paper, Scissors, and MORE!"


## Project Description
This will be a simple python program to cure your boredom. Now in our opinion, Rock, Paper, Scissors is VERY very boring on its own. But what if we added a twist? This program will add spice and fun into the original game by adding more "characters".

## Features
- Menu feature displaying the guide, the two different modes; lock-in mode & classic mode.
- Score display for both modes.
- Handles invalid inputs.

## How to run the program
1. Make sure python is installed
2. Download the file "rpsetc.py" *Rock, Paper, Scissors, and MORE! shortened*
3. Open the terminal
4. Run the program
5. Pick any from the choices (classic mode (practically infinite mode), lock-in mode, guide, and exit)
6. Guide is just the list of what beats what such as "Rock beats Paper"
7. After you pick a game mode, the user will pick any "characters" from the choices and if you win you will go on to the next round, if you lose you can see your score and then you go back to the main screen only in lock-in mode (in class mode it will just keep going until you choose to stop)
